# Dream Matches Web

A Next.js 15 application for creating dream matches between characters from different universes using AI-generated videos.

## Features
- **Character Selection:** Choose two fighters from various universes (Anime, Cartoon, WWE, AEW, Toku).
- **Match Initiation:** Start an epic battle between selected characters.
- **Match Result:** View the status and eventually the AI-generated video of the match.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript

## Getting Started
1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `src/app`: Application routes and pages.
- `src/components`: Reusable UI components.
- `src/data`: Mock data and types.
